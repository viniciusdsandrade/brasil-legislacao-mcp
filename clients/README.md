# Clients

Each folder has the installation files for one MCP client. The core of leis-mcp does not change for a client.

| Folder | Client | Status |
| --- | --- | --- |
| [claude-code](claude-code/README.md) | Claude Code | Ready |
| codex | Codex | Planned |
| grok | Grok | Planned |
| antigravity | Antigravity | Planned |
| glm | GLM | Planned |

To add a client, make a new folder with a README and the configuration file of the client. Use the command `leis-mcp` (stdio) and the environment variables of the main [README](../README.md#configuration).
